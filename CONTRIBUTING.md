# Contributing

Contributions that improve accuracy, clarity, accessibility, or reproducibility
are welcome.

## Before Opening a Change

1. Check whether the claim is printer-neutral or clearly label its limits.
2. Prefer primary documentation or reproducible experimental evidence.
3. Separate observation from inference and recommendation.
4. Name every variable held fixed and every variable changed.
5. Add attribution for methods, models, images, and data you did not create.
6. Avoid universal values unless a source establishes a universal constraint.

## Writing Style

- Explain the physical reason before the setting name.
- Define a term the first time it appears.
- Give the reader a pass/fail rule, not merely a picture to admire.
- Keep slicer-specific names in examples, with generic equivalents nearby.
- Use SI units and include formulas where they prevent ambiguity.
- Do not recommend changing multiple coupled variables in one diagnostic step.

## Evidence for New Recommendations

Please include:

- printer motion type and firmware;
- extruder, hotend, nozzle material, nozzle diameter, and wear state;
- filament manufacturer, product, material, color, lot when known, and drying;
- slicer and version;
- layer height, line width, speed, acceleration, and cooling;
- chamber and ambient conditions when relevant;
- exact test procedure, measurements, photos, and limitations.

Use [templates/experiment-log.md](templates/experiment-log.md) as a starting
point.
