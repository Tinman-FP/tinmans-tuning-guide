# Code of Conduct

Be precise, constructive, and kind.

Disagreement about methods is useful when it is tied to evidence. Critique the
claim, test design, or interpretation, not the person. Welcome beginners, state
assumptions, correct errors openly, and give credit generously.

Harassment, discrimination, threats, doxxing, and deliberately unsafe advice
are not acceptable. Repository maintainers may edit or remove contributions
that violate these expectations and may restrict participation when needed to
protect the community.

To report a concern privately, contact the repository owner through the contact
options on the GitHub profile.
