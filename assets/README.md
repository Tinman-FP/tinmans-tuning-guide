# Artwork and Provenance

## TinmanX1 Logo

`tinmanx1-thumbnail-logo.png` is the original high-resolution thumbnail icon
used by the TinmanX1 project. William Tinney identified this as the required
logo for the guide cover.

Source asset:

```text
TinManX1_1024.png
1024 x 1024 pixels, RGBA PNG
SHA-256: b9b0d6d01c86a32f3eb6fb82f2d979e3a7acaae0bd0325f17d7ca3362d3aa591
```

The repository copy has the same SHA-256 digest. It has not been redrawn or
replaced.

## Cover

- `tinmans-tuning-guide-cover.svg` is the editable `1600 x 900` source.
- `tinmans-tuning-guide-cover.png` is the GitHub-ready rendered cover.
- The SVG references the adjacent original logo asset and preserves its aspect
  ratio.
- The PNG was rendered from the SVG with librsvg at `1600 x 900` pixels.

The circular title composition, calibration-ring motif, typography, and layout
were created by Codex, OpenAI, at William Tinney's direction.
